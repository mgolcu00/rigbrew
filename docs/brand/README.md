## Rules

- **Mark**: an open frame (the machine) with a chamfered module seated inside (the model). Never close the frame, never rotate it, never put it inside another shape other than the app-icon tile.
- **Wordmark**: `rigbrew`, one word, lowercase, Martian Mono, "rig" at weight 600 and "brew" at 300. No colour inside the wordmark.
- **Colour**: aluminium neutrals and one accent, steel blue. Green means only "fits this machine". No gradients except the icon tile. No amber, copper or brown.
- **Type**: Martian Mono for headings and names; Departure Mono for labels and badges at 11 px (or multiples), uppercase; Instrument Sans for text; Commit Mono for numbers and code.
- **Voice**: English, short, concrete, measured. Say the number when there is one. No beer or coffee jokes, no "powerful", "seamless", "blazing".
- **Not checked yet**: a trademark and logo similarity search for the mark.
